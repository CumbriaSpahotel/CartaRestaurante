# Registro de Versiones del Sistema

Este documento mantiene el control de versiones unificado del proyecto **Carta Restaurante**.

> **Regla de versionado único**: El sistema comparte una única versión global. Cada vez que se realice cualquier modificación en uno o más módulos o archivos del sistema (`*.html`, `*.js`, `*.css`, `*.json`, etc.), se incrementará el número de versión global del proyecto siguiendo versionado semántico (`MAJOR.MINOR.PATCH`) y se registrará la fecha y los cambios correspondientes.
